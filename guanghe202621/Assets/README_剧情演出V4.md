# 《堂吉诃德》V4 剧情演出与游玩小气泡

## 直接运行

1. 打开 `Assets/Scenes/Main.unity`，点击 Unity 运行，再点游戏内的“开始游戏”。
2. 主角先从小屋浮现并走到原起点，随后开场黑幕和场景旁白逐字自动播放。角色气泡播完后出现右侧选项，点选后进入对应的回应或剧情分支。
3. 点击最后一个开场选项后，主角会自行冲进村口坑。接下来的正式对白可以点击纸张对话框、“继续”或按 Enter 翻页。对话结束后按 R，或者双击主角，回到火堆继续剧情。
4. 之后按提示拖石头、粘硬纸板、空格出发。ESC 仍然打开原暂停菜单；HUD 重置按钮仍需二次确认。

场景中的 `V4剧情场景绑定` 已指定主角、相机、村口石头、火堆、镜头目标和触发区，不需要再手工绑定按钮 onClick。

当前按参考图排版：左上是暂停书本，右边横排三个小圆形道具图标；右上回转箭头沿用“重置关卡并二次确认”。左侧是半身立绘，底部是纸张对话框，A/B 选项在右侧偏上。出现选项时，底部保留角色上一句对白和表情。剧情时道具图标仍常驻，但暂时屏蔽悬浮说明；按 ESC 或点击书本仍能打开暂停菜单。

## 改台词：不用改代码

选中 `Assets/Resources/UI/PresentationLibrary.asset`：

- 在“选择章节”中选择某一幕，然后在“选择台词/镜头节点”中选择一句。
- 改“台词”“说话人”“选项文字”即可。保留“节点标识”和“下一节点”，以维持现有分支连接。
- 选中对白节点，在“堂吉诃德表情”选择主角差分，共有 21 张正式表情。说话人为“帕洛梅克”时，使用“帕洛梅克表情”选择通常、嘻嘻、心虚或苦恼。语气和表情提示填在对应字段，台词栏只放玩家要读的文字。
- 长对白和报幕优先按完整句子及纸框实际大小分页，每页最多两行，给纸框边缘留白。整句放不下时按逗号、分号等自然停顿拆开，避免下一张只剩“了。”等尾字。台词里按一次 Enter 另起一行，留一行空白会从下一页开始。普通对白的「继续」先补全正在播放的字幕，再推进到下一页。旁白在每页字幕播完后自动停留和翻页，停留时间可以在节点里调整。
- 正文、旁白、选项和气泡共用中文换行规则，句号、逗号、右引号等标点会跟随前文。
- 右侧选项沿用预制体里的纸框。短选项可用到 40 号字，长文字自动换行，纸框按内容增高。两项需要共用有限空间时会调小字号。
- 教学和游玩小台词在下面的折叠栏，支持首次台词、第二次短句、第三次短句、显示时间、冷却和优先级。
- 点“检查所有分支连接”可以检查入口、选项和下一节点引用。
- 16 段主线和 40 组教学／小台词已录入。`PresentationV4.json` 用于重建初始配置，日常修改 `.asset` 即可。

需要反复测试某一段：运行并开始游戏后，打开顶部菜单 **堂吉诃德 → 剧情 → 打开剧情预览窗口**，选章节播放。它只存在于编辑器，不会给正式游戏增加演示按钮。预览结束可点“结束预览并恢复操作”。

## 美术替换位置

全部是已有预制体，运行时只实例化，不用脚本创建面板：

| 预制体 | 修改内容 |
| --- | --- |
| `Resources/UI/StoryPanel.prefab` | 底部对话框、角色名、选项按钮、居中旁白纸框、黑幕和结束图布局 |
| `Resources/UI/HeadBubble.prefab` | 角色头顶小气泡，Background 使用自带尾巴的 `IMG_1197`。可调整字体和边距 |
| `Resources/UI/GameplayItemTray.prefab` | 游玩时右上方三个道具的图片、名称和悬浮区 |
| `Resources/UI/PresentationRuntime.prefab` | 引用上面三个预制体和台词配置；打字机开关默认关闭 |

主角对白使用 `Resources/UI/UI/bqcf` 中的正式半身稿。在 `PresentationLibrary.asset` 的立绘栏和「堂吉诃德其他表情差分」列表中可以替换相应 Sprite。各差分使用同尺寸画布，切换时人物位置一致。在 `StoryPanel.prefab` 的 `Portrait_替换透明立绘PNG` 调整共用的位置和大小。老板立绘和结束图也在 `PresentationLibrary.asset` 中设置，留空时仍显示名字、对白和「未完待续」。

第三幕老板「帕洛梅克」已接入 `UI/bqcf/YDLB` 的通常、嘻嘻、心虚、苦恼四种半身立绘。`PresentationLibrary.asset` 的「旅馆老板立绘」为通常表情，「帕洛梅克表情差分」配置其他三种。对白节点的说话人填写“帕洛梅克”，再选择对应表情即可。切到另一位说话时，未发言者保留上一张表情，不会重置回默认图。

旅馆委托、交差、跑鞋揭晓三个章节已勾选「堂吉诃德与帕洛梅克双人同屏」。主角在左、老板在右，说话者正常亮度，另一位默认 70% 亮度，透明度保持不变。打开 `StoryPanel.prefab`，在根物体的 `StoryPortraitStage` 中调整「未说话角色亮度」，数值越小越暗；在左右 Image 的 RectTransform 中调整大小和位置。布局属于预制体，运行代码只切图、开关和调颜色。其他章节继续使用原单人模式。

委托的纯选项节点继续隐藏两位立绘和上一句纸框。其他右侧选项默认暂时隐藏右侧老板立绘，左侧主角与上一句正文保留，避免选项遮住老板的脸；恢复普通对白时，两位立绘自动回来。若以后移动了选项位置，可以取消 `StoryPortraitStage` 的「右侧显示选项时隐藏右侧立绘」。

`StoryPanel.prefab/SkySubtitle/SkyText` 是无描边、无纸框的天空字幕，位置在上方中央的较窄区域，避开两侧柱子和角落按钮。旅馆门外的找马旁白按意群分成三行居中，同一页完整显示；天空字幕单独允许最多四行，普通对白仍按每页最多两行分页。`EquipmentNotice` 是拾取跑鞋时短暂出现的装备提示，文字和图标可在预制体里直接改。天空字幕、开场字幕、旁白和重置提示均不添加描边或阴影。底部纸卷及其美术边线保留。

村口开场、看坑和看石头采用水平镜头。看坑时在 `Main` 场景的「镜头目标」里配置正交尺寸，保持高度推近后平移回玩家视角，恢复原来的变焦。村口坑壁背景在 `Grid/村口坑壁_背景_无碰撞`，坑底和碰撞在 `Grid/Ground`。

底部纸张使用 `UI/uisc/IMG_1126.png`，A/B 花纹框使用 `IMG_1180.png`、`IMG_1183.png`。`PresentationRuntime` 上的「显示大立绘时隐藏场景角色外观」控制对白期间的角色显示。

在 `StoryPanel.prefab` 的纸张对话框下，`SpeakerNameplate` 的子物体 `Speaker` 显示角色名。大纸卷里的 `Content` 显示对白，可在其 Inspector 调整文字行距、正文字距和矩形边距。角色名默认 48，正文默认 40，长对白分到后续页面。

在 **停止运行** 时编辑 Project 中的预制体并保存。若在场景实例上调整，按需要用 Overrides → Apply 写回该预制体。运行中的临时实例调整在停止后不会保存。

| 实际拾取瓷瓶、巧克力、画像 | 各自播放专属气泡；最后接「全部集齐，回一楼交差」，全程不暂停、不锁操作 |

| 约 18 秒没有操作 | 闲置小台词 |

“拆错支撑导致桥塌”需要关卡程序确认因果关系，因此保留明确事件接口，不会把普通物块落地误判成剧情事故。其他地图的“卡在坑底”“通过歪桥”等，也可以用同一接口或 `StorySignalTrigger` 配置触发。

所有游玩小气泡都不暂停、不调用主线对话锁、不抢鼠标事件。之后的键盘、拖拽等操作可打断；同一个触发输入不会立刻把新气泡清掉。主线对白期间允许 ESC 暂停，暂停时隐藏剧情层和气泡，继续后恢复当前节点。

剧本标注的小气泡用「主线头顶气泡」节点。需要边显示边等动作时，在「等待玩法信号」节点勾选「等待期间显示头顶小气泡」。普通对白使用底部大纸卷和角色名牌。居中的纸框由「居中旁白」节点自动播放；旅馆门外的「天空字幕」使用独立的上方文字，逐字显示、停留后自动消失，不需要点继续。开场气泡逐字出现，读完后自动消失并显示右侧选项。普通对白后的选项可以保留上一页正文；勾选「选项出现时隐藏上一句与立绘」则只显示选项，帕洛梅克委托的回应已按此配置。空白的普通对白节点会直接跳过。

## 其他程序怎么调用

原项目里的角色、拾取、硬纸板和死亡区域已接好，不需要重复调用。新机关只在事实发生后通知：

```csharp
using GamePresentation;

// 确认“拆支撑导致桥塌”以后调用；不会改变你的桥或玩家物理。
PresentationEvents.Report(PlayEvent.SupportCollapsed, player, this);

// 新的坑底卡住检测，第二个参数用同一个机关组件，便于按位置降频。
PresentationEvents.Report(PlayEvent.StuckInPit, player, this);

// 自己的关卡入口完成后，通知既有主线。
PresentationEvents.Signal("inn.enter", this);

// 自定义章节/小台词，标识与配置资产中的 id 一致。
PresentationRuntime.Instance.Director.Enqueue("inn.shoes");
PresentationRuntime.Instance.PlayBark("tree_near_miss", this);
```

UnityEvent 不想写一行代码时：添加 `PresentationEventRelay`，填写事件/章节/信号/小台词标识，再绑定相应的公开方法。区域进入触发用 `StorySignalTrigger`（BoxCollider2D 自动设为 Trigger）。

三个教学标记就是 `flag_taught_midstop`、`flag_taught_underfoot_lock`、`flag_taught_run_lock`，可从 `PresentationRuntime.Instance` 读取。切关、R 重置、HUD 重置均不清除；开始全新周目时才调用 `ResetTutorialProgress()`。它们是本次运行的全局进度，不写进美术预制体或配置资产，也不写 PlayerPrefs。

## 镜头与新关卡复用

`V4剧情场景绑定` 的“镜头目标”是标识与场景 Transform 的对应表。改物体位置或替换美术时，拖好对应目标即可，不依赖层级名称查找。

镜头按配置平滑移向目标、停留、再自动返回关卡原相机目标和原变焦。不会关闭整个角色控制器；角色不需要走出镜头才会恢复。`inn_wall,inn_stairs` 表示连续看两处再返回。

新关卡：放入 `PresentationSceneBinding`，拖入玩家、相机和 `PresentationRuntime` 预制体；配置本关目标与触发区。已有全局管理器会复用，教学不会重播。只需要小台词时取消勾选“启用 V4 主线”。

“本关自动播放的章节”可以改成 `bridge.intro`、`inn.intro` 等，留空则只等本关触发器。剧本中标注待关卡定稿的跳跃小关，已按当前跷跷石板布局适配那一句提示和镜头目标，未改动队友的机关。

当前 Main 使用新版第三幕：门外 `inn.approach` 天空字幕 → 吧台 `inn.intro` 帕洛梅克委托与两个玩家回应 → 按是否已学会半路叫停进入对应教学分支 → 按原玩法顺序拾取瓷瓶、巧克力、画像 → 回吧台触发 `inn.quest_done` → 原 InnQuest 抛出跑鞋 → 实际拾取后显示装备提示及 `inn.shoes` 鞋子身份揭晓、帕洛梅克解释 → 实际破墙后 `inn.ending` 原型收尾。台词里的表情提示使用差分字段，不显示在正文中。其他程序继续使用原 InnQuest 和拾取组件，演出只接收成功事件。

场景绑定器的“保留三物品收集与老板抛奖励任务”默认开启。关闭此项、保留“启用 V4 主线”，可使用队友原来的阁楼取跑鞋流程；同时需按该版本恢复 inn.intro 与 inn.shoes 的台词。关闭 V4 主线时继续使用原 BubbleDialogSequence 老板对白。玩法镜头仍由原 CameraTarget 检测与历史坐标判定控制，剧情镜头只临时接管，结束后恢复原机位和缩放。
